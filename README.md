An evolving developer environment built around isolated code sandboxes, AI orchestration, authentication, notifications, and Kubernetes infrastructure.

### [Customer Support AI Agent](https://github.com/VishwakarmaSanket/customer-support-ai-agent)

A support workflow that combines intent classification, semantic retrieval, grounded response generation, and human escalation. Built with an emphasis on knowing when the system has enough evidence to answer safely.
